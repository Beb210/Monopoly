# Monopoly

Классическая настольная игра «Монополия», реализованная на Unity

##  Особенности

- **Физические 3D-кубики** с реалистичной физикой и автоматическим определением выпавшей грани
- **Игровое поле из 40 клеток**: улицы, железнодорожные станции, утилиты, налоги, карты «Шанс» и «Общественная казна»
- **Пошаговая система** для 4 игроков (1 человек + 3 бота) с потенциалом расширения до многопользовательской игры!
- **Полная игровая механика**: покупка собственности, аренда, строительство домов и отелей
- **Механика тюрьмы**: выход через оплату, карту или дубль
- **Покупка у других игроков** с наценкой 50%
- **Анимация движения фишек** с индивидуальными смещениями для каждого игрока
- **Звуковые эффекты** шагов с сохранением настроек между сессиями

## ️ Архитектура проекта

### Основные компоненты

**GameBoard.cs** — центральное хранилище данных игрового поля
- Содержит массив из 40 объектов TileData с полной информацией о каждой клетке
- Управляет картами «Шанс» и «Общественная казна»
- Предоставляет методы для получения позиции клетки, нормализации индексов (с учётом кругового поля)
- Отвечает за установку владельцев клеток и спавн маркеров собственности

**TurnManager.cs** — менеджер игровых ходов
- Координирует всю игровую логику: броски кубиков, движение, покупки, аренду, тюрьму
- Управляет состоянием кнопок UI в зависимости от контекста (тюрьма, дубль, режим строительства)
- Обрабатывает клики мыши для взаимодействия с клетками поля
- Содержит базовый ИИ для ботов

**PlayerPawn.cs** — определяет логику передвижения фишек по игровому полю
- Анимация прыжков по клеткам с параболической траекторией
- Индивидуальные смещения для каждого игрока
- Отдельные смещения для тюрьмы
- Автоматический поворот фишки в зависимости от стороны поля

**Dice.cs / DiceRoller.cs** — система кубиков
- Dice.cs: физический кубик с Rigidbody, определяет выпавшую грань через сравнение нормалей с Vector3.up
- DiceRoller.cs: управляет броском двух кубиков, создаёт невидимые стены для ограничения зоны, ждёт остановки и определяет результат

**TileData.cs** — данные одной клетки
- Хранит всю информацию: название, тип, цена, цвет группы, аренда, владелец, количество домов
- Метод GetRent() рассчитывает текущую аренду с учётом монополии, домов и типа клетки

### Паттерны и решения

**Событийная модель**: DiceRoller использует событие OnDiceRolled, на которое подписывается TurnManager — это развязывает физическую систему от игровой логики.

**Корутины для анимаций**: все движения фишек и задержки реализованы через IEnumerator с yield return, что позволяет писать последовательный код для асинхронных операций.

**Состояния UI**: система кнопок управляется через метод SetGameplayButtons() с именованными параметрами — это делает код читаемым и снижает вероятность ошибок при переключении состояний.

## Как запустить

### Требования
- Unity 2022.3 LTS или новее
- Unity Input System (устанавливается через Package Manager)
- TextMeshPro (обычно установлен по умолчанию)

### Инструкция
1. Клонируйте репозиторий
2. Откройте проект в Unity (File → Open Project → выберите папку)
3. Дождитесь импорта ассетов и компиляции скриптов
4. Откройте сцену Assets/Scenes/MainScene.unity
5. Нажмите Play в редакторе

### Настройка в Inspector
- **GameBoard**: назначьте 40 трансформов клеток в массив tiles
- **TurnManager**: назначьте фишки игроков в массив pawns, кнопки UI в соответствующие поля
- **DiceRoller**: назначьте зону броска в diceRollArea

### Почему TurnManager такой большой?

Класс TurnManager содержит всю игровую логику в одном файле. Это осознанное решение для учебного проекта — вся логика в одном месте для простоты понимания и отладки.

**TODO для улучшения**: разнести по паттерну State (NormalTurnState, JailTurnState, BuildState, CardDrawState и т.д.).

### Физика кубиков

Кубики используют Rigidbody для реалистичной физики. Определение выпавшей грани происходит через сравнение нормалей граней с мировым Vector3.up — это работает независимо от ориентации кубика.

### История коммитов

История коммитов в этом репозитории структурирована логически для удобства навигации. Код загружен из оригинального проекта, история изменений которого не сохранилась.
